# 👤 AI Based Face Recommendation System

An intelligent AI-powered face recommendation system that analyzes facial features using Machine Learning and Computer Vision techniques to generate smart recommendations based on face similarity and recognition.

---

## 📌 Project Overview

The **Face Recommendation System** identifies and compares facial patterns from uploaded images using AI algorithms.

The system performs:

* Face Detection
* Face Recognition
* Feature Extraction
* Similarity Matching

It detects a human face, extracts unique facial embeddings, and recommends the most similar faces from the dataset.

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/face-recommendation-system.git
```

2. Navigate to project folder:

```
cd face-recommendation-system
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the application:

```
python app.py
```

---

## 📊 How It Works

1. Upload an image
2. System detects face using OpenCV
3. Extracts facial features
4. Compares with dataset
5. Returns most similar face recommendations
